# Clan playbook

The rules the agent clan runs by. Stronghold owns and serves these files; edit them here and
commit, so every rule change has a diff and a history. The files say `{user}` for the person who
runs the clan; Stronghold fills in the name from Settings → General when it serves them.

- `AGENT-FLEET-PLAYBOOK.md`: coordinators (and the fallback attendant).
- `_AGENT_PROTOCOL.md`: every dispatched worker.
- `ATTENDANT-BRIEF-TEMPLATE.md`, `KICKOFF-TEMPLATE.md`: templates filled in per Run / track.
- `ENVOY-PLAYBOOK.md`: the Envoy, the user's Slack diplomat (role `envoy`). It is not a worker.

`~/Documents/agents/` holds symlinks to these files, so older kickoff specs and memory files
that point there keep working.
